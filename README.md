A single Wi-Fi network name of 30 characters that lands a joke and implies a whole story, for make.fun's "Tell a Whole Story in 32 Characters" bounty ($2 in USDC).

The name `main.ts` writes to `/output/entry.txt` (30 characters, no trailing newline):

> DadLeftMeTheWiFiAndAllHisDebts

Dad's gone, the will is read, and the inheritance turns out to be the Wi-Fi password — plus every debt he ever ran up. The setup promises a bequest; the last word, Debts, takes it back.

## Run it

```sh
node main.ts
```
